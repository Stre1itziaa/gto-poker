# 02 · 核心数学手册（公式 + 速查表）

> 所有数字经公式推导 + 至少两个独立来源交叉验证（GTO Wizard 原文算例、TwoPlusTwo 计算帖、Wikipedia）。本文件是全知识库的"数学底座"。

## 1. 底池赔率（Pot Odds）

面对下注 b（底池为 p），跟注所需胜率：

**所需胜率 = b / (p + 2b)**（跟注后底池变为 p + 2b）

| 对手下注尺度 | 跟注所需胜率 | 约合赔率 |
|---|---|---|
| 25% pot | 16.7% | ≈ 5:1 |
| 33% pot | 20.0% | 4:1 |
| 50% pot | 25.0% | 3:1 |
| 2/3 pot | 28.6% | ≈ 2.5:1 |
| 75% pot | 30.0% | ≈ 2.3:1 |
| 100% pot | 33.3% | 2:1 |
| 150% pot | 37.5% | ≈ 1.67:1 |
| 200% pot | 40.0% | 1.5:1 |

## 2. Alpha 与 MDF（一对镜像公式）

- **Alpha α = b / (b + p)**：诈唬方需要的最低对手弃牌频率，诈唬才不亏（= risk/(risk+reward)）。
- **MDF（最小防守频率）= p / (p + b) = 1 − α**：防守方为阻止对手"无限诈唬获利"，必须用范围中至少这么大的比例继续（跟注或加注）。

| 下注尺度 | Alpha（对手需弃牌%） | MDF（需防守%） |
|---|---|---|
| 25% pot | 20.0% | 80.0% |
| 33% pot | 25.0% | 75.0% |
| 50% pot | 33.3% | 66.7% |
| 2/3 pot | 40.0% | 60.0% |
| 75% pot | 42.9% | 57.1% |
| 100% pot | 50.0% | 50.0% |
| 150% pot | 60.0% | 40.0% |
| 200% pot | 66.7% | 33.3% |

**注意事项**：
- 公式**只适用于初始下注**。面对加注要用"风险/(风险+回报)"重算：例：$60 进 $100 底池被加到 $200，新 α = 200/(200+100+60) ≈ 55.5%，MDF ≈ 44.5%。
- MDF 只在均衡框架下有意义。**对手弃牌过多/诈唬过少的真人局，过度防守反而错**——MDF 是被误用最多的公式之一。

## 3. 河牌圈价值 : 诈唬比（Value : Bluff）

河牌极化下注时，均衡诈唬占比 = **b / (p + 2b)**——恰好等于对手跟注所需胜率，使其 bluff catcher 跟注与弃牌无差别：

| 河牌下注尺度 | 诈唬占比 | 价值 : 诈唬 |
|---|---|---|
| 33% pot | 20% | 4:1 |
| 50% pot | 25% | 3:1 |
| 75% pot | 30% | ≈ 2.3:1 |
| 100% pot | 33.3% | 2:1 |
| 150% pot | 37.5% | ≈ 1.67:1 |
| 200% pot | 40% | 1.5:1 |

**勘误（重要）**：网络流传的「1/3 pot ≈ 2.7:1、满池 ≈ 1:1、2x 超池 ≈ 1:2」是**错的**。正确值为 4:1、2:1、1.5:1。且诈唬占比 = b/(p+2b) 随 b→∞ 渐近逼近 50%，**河牌均衡中诈唬永远不多于价值**。
**河牌之前的街**：诈唬频率可以高于上表，因为半诈唬带权益、且早街下注有弃牌权益与杠杆。

## 4. 几何尺寸（Geometric Sizing / 铺码）

**定义**：每条街下注相同的底池比例，使到河牌时正好全下。底池按 (1+2b) 每街复利增长，最大化对手投入的钱。

**公式**：设剩余底池 P、剩余有效筹码 S、剩余下注街数 n，则每街下注比例：

**b = [(1 + 2S/P)^(1/n) − 1] / 2**

验证算例：底池 100 / 剩余筹码 500 / 剩 3 街 → b ≈ 61.2%；底池 5.5bb / 剩余 97.5bb / 剩 2 街 → b ≈ 252% pot。

| 场景 | SPR（S/P） | 几何尺寸 |
|---|---|---|
| 翻牌起剩 3 街 | ≈ 7.3 | ≈ 每街 75% |
| 翻牌起剩 3 街 | ≈ 13（典型 100bb 单加注锅） | ≈ 每街 100% |
| 转牌起剩 2 街 | ≈ 4 | ≈ 每街 100% |
| 转牌起剩 2 街 | ≈ 1.03 | ≈ 每街 75% |

**勘误**：「几何尺寸 ≈ 每街 75%」**不是普适常数**，只是 SPR≈7.3 且剩 3 街时的特例。适用前提：我方范围极化、对手范围被封顶（capped）——这时铺码能把对手的价值最大化。

## 5. SPR（Stack-to-Pot Ratio）

**SPR = 有效筹码 ÷ 底池**。衡量"投入深度 ↔ 所需手牌强度"：

- **SPR ≲ 3（低）**：顶对/超对即可轻松全下承诺。
- **SPR ≳ 10（高）**：需要更强的成手才值得打光筹码。
- 翻牌前可通过加注尺寸主动"设定"目标翻牌 SPR，与几何尺寸联动规划整手牌的筹码铺设。

## 6. 隐含赔率与反向隐含赔率

- **隐含赔率（implied odds）**：直接底池赔率不足时，若成牌后能在未来街再赢钱（深筹码同花/顺子听牌），跟注仍可盈利。粗略心法：听牌越隐蔽、对手越强且筹码越深，隐含赔率越高。
- **反向隐含赔率（reverse implied odds）**：跟注后即使"成牌"仍常是第二好——赢时赢得最少、输时输得最多。典型：小踢脚同花听牌、卡顺听牌、被压制的暗三条。有反向隐含赔率时，名义底池赔率够也不该跟。

## 7. 一张图记住三件套的统一逻辑

```
攻击方下注 b 进底池 p：
  对手弃牌频率 d，诈唬 EV = d·p − (1−d)·b
  → d = b/(b+p) = α 时诈唬不亏不赚     …… Alpha
  → 防守至少继续 1−α = MDF             …… MDF
  → 若是河牌价值下注，诈唬占比也应 = α
     使对手 bluff catcher 无差别       …… V:B 比
（同一个分数 b/(b+p)，三个身份）
```
