**日期**：2026-10-02　**状态**：待拍板（本文档只定方向，未动代码）
**评审基准修正**：APK 自 v0.3 锁 `sensorLandscape`，**横屏（740×360 量级）是玩家实际主视图**——本方案以横屏为第一基准重新取证；竖屏仅为 Web 端兜底，降为次要章节。

## 1. 总体方向

**从「网页信息陈列页」转向「主机级 Start 画面」**：
- 每一屏只有一个主视觉 + 一个主行动，其余全部降级。
- 唯一强调色制度：樱→金渐变**只给主 CTA**，其余交互一律降饱和描边；语义色只留胜利绿/失败红。
- 动效预算：一屏一个呼吸焦点（主 CTA），其余静态。

## 2. 界面分区（横屏主基准 1280×720；竖屏为纵向镜像）

### 2.1 大厅（重灾区，优先做）
```
横屏：                              竖屏：
┌──────────────────────┬─────────┐  ┌──────────────────┐
│ 顶状态条 48px        │         │  │ 顶状态条 48px    │
│ (logo ───── 玩家chip)│         │  ├──────────────────┤
├──────────────────────┤ 次级入口 │  │                  │
│                      │ (角色库/ │  │   立绘 (65vh)    │
│   立绘 (78vh)        │  图鉴/  │  │   名牌→右下角小牌 │
│   名牌右移缩小 22px  │  数据)   │  │                  │
│                      │ 竖排列  │  ├──────────────────┤
├──────────────────────┤         │  │ ▶ 开始对局 (主CTA)│
│ 主 CTA 条: ▶ 开始对局 │         │  │  次级横排 icon    │
└──────────────────────┴─────────┘  └──────────────────┘
```
- **统计 chips 从顶栏撤除**（数据页可查），顶栏只留 logo + 玩家段位 chip。
- **名牌（角色名/称号/台词）从居中置顶改为右下小牌**，22px 名字，台词并入气泡。
- **底部主 CTA**：`▶ 开始对局` 高 52px 渐变实心+微呼吸；桌型选择做成 CTA 内的细分段器（6人/4人/单挑），不再单独一行。
- 好友房/角色库/图鉴/数据 = 次级入口（横屏右列竖排 / 竖屏 CTA 下方横排 icon）。

### 2.2 牌桌（横屏主基准——本次最大改造点）
```
┌────────────────────────────────┬────────┐
│ 顶状态条 40px（手数/盲注/菜单⚙）│        │
├────────────────────────────────┤ 侧栏   │
│        桌面区 ≥70% 屏高         │ 212px  │
│   (椭圆+公共牌+底池+座位环绕)    │ 教练+  │
│   现状 53% → 行动条瘦身后来到    │ 日志   │
├────────────────────────────────┤        │
│ 行动条 ≤88px 两态：             │        │
│ 默认: [弃牌][过牌/跟注] [▶加注]  │        │
│ 展开态: +滑条150px+快捷注chips   │        │
│ (点加注/再点空白处 切换)         │        │
└────────────────────────────────┴────────┘
```
- **行动条两态化（横屏第一刀，168px→≤88px）**：默认单行三键——弃牌=红字描边**窄**、过牌跟注=绿字描边、**加注=实心渐变宽主视觉**；`action-hint` 提示行合并进三键行左侧或改为浮层；滑条+快捷注只在点"加注"后滑出（二级面板盖在桌面下缘，半透明），确认/取消收回。修滑条 90→150px（flex-basis 固定，不再被压缩）。
- **座位可读性**：name 11→12px，筹码等宽数字且与底牌分行（修叠压），座位板底 .88→.92。
- 桌面装饰（樱花/格纹）透明度 -30% 让位信息。

## 5. 分辨率适配方式（规范化现有断点）

| 档 | 判定 | 策略 |
|---|---|---|
| 竖屏手机 | ≤860w | 纵向镜像流（§2 图）；立绘高度 aspect-ratio 锁定防 21:9 拉长 |
| 横屏矮窗 | ≤560h 且 landscape | 三段流+侧栏 220px（已上线 v0.3，微调即可） |
| 折叠屏内屏 | 861-1180 | 竖屏流放大，字号 clamp(14,1.1vw,16) |
| 桌面 | ≥1181 | 中央 16:9 舞台 letterbox，两侧氛围延伸（backdrop 复用） |
- 弹性一律 `clamp()/min()`，不再新增硬断点；安全区四向 env()（已做顶部/底部，**补左右**——横屏挖孔在侧边）。

## 6. 重点优化区域（横屏主基准，优先级排序）

1. **P0 牌桌行动条两态化**——横屏实测 168px（47% 屏高）压死桌面；瘦身到 ≤88px + 快捷注单行化（86→36px）+ 修滑条 90→150px（v0.3 的 flex 失效 bug）+ 三键主次。
2. **P0 大厅内容超载**——台词块 164px 收进气泡/右下小牌（修名牌出屏 30px+立绘溢出 74px）+ 撤顶栏统计 + 底部主 CTA。
3. **P0 长列表界面三件套换形态**——角色库 6.3 屏/图鉴 7.8 屏/数据页 11.9 屏，纵向长列表在横屏全部错误：
   - 角色库 → 单角色大图+左右切换（一次一人，滚动归零）；
   - 图鉴 → 全屏页+角色分页签（每页 8-10 格一屏尽收）；
   - 数据页 → 横屏全屏抽屉+图表横向布局（图表区 ≥240px 高，列表左右双栏）。
4. **P1 色板/字阶/控件 token 化**——一次变量重构，全站统一。
5. **P1 座位信息可读性**——12px 底线+等宽数字+筹码与底牌分行。
6. **P2 桌面 letterbox + 横屏左右挖孔安全区 + 表情 chips 65→44px**

**竖屏 Web 兜底**（P1 尾批）：行动条两态化自动受益；名牌/入口主次随 token 化顺手迁移，不单独立项。
