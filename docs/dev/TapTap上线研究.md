## 三、合规动作清单（上架前必须做）

1. **去货币化确认**：筹码不可兑换、无任何充值入口、无奖励提现——当前架构天然满足 ✓
2. **防沉迷接入**：未接会被卡审核（TapTap FAQ 明示）——需接 TapTap 防沉迷 SDK（Android 包内）
3. **隐私政策**：游戏收集昵称（gto-name）→ 需内置隐私政策页
4. **AIGC 声明**：立绘/场景为 AI 生成 → 按规范在商店页与游戏内声明（与 Steam 线同一份清单）
5. **命名预案**：《夜樱扑克部》含"扑克"敏感词，驳回概率存在。备选：《夜樱部室：GTO 训练》《夜樱牌室》——先投现名，驳回即换

## 四、技术打包（Android APK）

| 方案 | 说明 | 工作量 |
|---|---|---|
| **Capacitor**（推荐） | WebView 壳，WebRTC 支持，包体小，社区成熟 | 1 会话 |
| TWA | 需游戏托管在公网 HTTPS + 域名资产验证 | 依赖部署 |
| Tauri v2 Mobile | 较新，与 PC 线同一套 | 待验证 |

依赖链核验（APK 内运行时）：
- PeerJS 信令 0.peerjs.com（公网）✓ 不依赖本地服务器
- STUN Cloudflare（已配，国内直连 0.2s）✓
- 本地 serve.js **不需要**——APK 内置全部静态资产（index/js/css/assets）
- 好友房 P2P：蜂窝网络间打洞概率高（蜂窝 NAT 多为 Cone 型）；对称 NAT 边缘情况无 TURN，提示换热点（已有话术）

## 六、建议路线

- **Phase 1（1-2 会话）**：Capacitor 打包 APK（内嵌全部资产，好友房 P2P 走公网信令）+ 隐私政策页 + 开发者注册

- **Phase 3（视驳回情况）**：改名重投 / 防沉迷 SDK 接入
- **长期**：软著办理（电子件 10-15 天）为未来"正式上线"铺路；Steam 线（Tauri）并行不冲突
