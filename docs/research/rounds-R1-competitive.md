# 迭代轮 · 竞技群（P01 / P05 / P06 / P08 / P12 / P17 / P18）

> 评价对象：当前版本（PNG 立绘角色系统 + 夜樱主题 + 教练面板 + 会话统计）。证据：`game/test/persona.js` 实测 + 浏览器实机走查。批评不接受「早期版本」豁免。

---

## P01 · 段位卷王·竞技型（28 岁男，玉之间车神）

**模拟**：400 手（全场最长），意图 VPIP 22%。
**实测**：实际 VPIP 16%、加注为主、全下 2 次、重买 3 次、bb/100 **−95.1**（±约 60）、最长连败仅 2。
**UI 实证**：无段位、无匹配、无对手列表、无牌谱导出、无历史战绩页。顶栏唯一战绩是「本会话盈亏」——关掉页面就清零。

**评价（不留情面）**：
他打开游戏 20 秒就会问出那个致命问题：「**段位在哪？**」没有答案。这个游戏给他的全部承诺是「和 5 个一模一样的机器人打无限局」——没有天梯、没有赛季、没有评级，赢 100bb 什么都不会发生，输 100bb 也什么都不会发生。一个为「证明自己变强」而来的玩家，在这里连变强的刻度都不存在。bb/100 −95 会让他合理怀疑机器人有暗桩（实际没有，是 1v5 结构性逆差 + 方差，但没有数据面板向他证明这一点）。教练面板那种「建议跟注 50」的保姆式提示对他反而是侮辱——他要看的是**自己的** leaks 统计，不是每手一句正确答案。
**留存预测：1 天内流失。** 他要的三样东西——段位、牌谱、对手差异——一个都没有。

**他提出的诉求**：段位/评级系统；牌谱导出（至少本局历史）；对手倾向统计；把「会话统计」升级为持久战绩页。

## P05 · 德州老炮（线下 live game 常客，35 岁）

**模拟**：300 手，意图 VPIP 20%，实到 16%，bb/100 −46.8（±50）。
**UI 实证**：5 个机器人策略完全同质（同一引擎），无怠慢型/跟注站/疯子区分；「读牌」只存在于教练面板的黑盒输出。

**评价**：
老炮的第一句话会是：「**这些 AI 打得一模一样。**」线下 live game 的乐趣是桌上有一个鱼、一个疯子、一块石头，然后你去剥削——这个游戏里 5 个座位坐的是同一个算法的 5 个分身，读牌这门手艺**没有任何施展空间**。次大的问题：机器人被改强之后（14.6% 面对下注加注率是 solver 量级），普通玩家体感是「这些 AI 会凭空变出牌」，而游戏没有提供任何方式让他理解这一点——没有手牌亮明复盘、没有胜率回放。他还会发现 betting interface 的预设只有比例加注，没有「2.5x/3x 开雷」这种 live 习惯表达。
**留存预测：给一次机会，2-3 天后流失**，除非给他「有破绽的对手」和「复盘工具」。

**诉求**：机器人性格差异化（松/紧/凶/弱，且会暴露可利用倾向）；本手结束自动摊牌复盘（双方范围+胜率曲线）；多桌/加桌。

## P06 · 日麻纯粹党（雀魂王座，把德州当异端）

**模拟**：100 手，VPIP 21%，bb/100 +157（小样本，忽略数值）。
**UI 实证**：无规则教学、无新手引导层；德扑术语（翻牌/转牌/河牌/MDF）无任何解释入口；没有日麻，也不会有。

**评价**：
「这不是我的游戏」——他本来就不该来。但让他恶评如潮的不是规则差异，而是**这个游戏假设你懂德扑**：首屏 366 字说明文里塞着 MDF、蒙特卡洛、诈唬比四个词，0 条术语解释，0 个教学关。日麻玩家是被雀魂「东风之里」教学 nurturing 过的，他们对「开局即深渊」的容忍度为零。角色立绘他会夸一句「画得还行」，然后补一句「可惜是德州」。
**留存预测：当天流失，且会告诉朋友「角色不错但玩不懂」。**

**诉求**：交互式新手教学（3 分钟带打一手）；术语悬浮解释；如果厂商真想接日麻盘子，加日麻模式——但这等于重做半个游戏，诚实标注为「不现实」。

## P08 · 赛事云观众（看 MPL/WSOP 直播，自己打得一般）

**模拟**：250 手，VPIP 18%，bb/100 +53.6（±45）。
**UI 实证**：无观战模式、无名局回放、无锦标赛结构（只有限注现金桌）、无锦标赛/卫星赛概念。

**评价**：
他看比赛是为了「名场面」——埋伏全下、河牌逆转、冠军级 read。这个游戏能提供的最接近物是全下后的逐街跑牌（有！这是亮点），但**没有观战席**意味着他连看别人打都做不到——这游戏连「别人」都没有。想复刻他在雀魂看 MPL 的体验，需要：锦标赛结构（MTT 升盲）、观战、回放、甚至解说字幕。全都没有。他会说：「这是一个陪练器，不是一个赛事宇宙。」
**留存预测：摸两天，等一个不存在的锦标赛，流失。**

**诉求**：MTT 锦标赛模式（升盲+淘汰）；对局回放与分享；观战 AI 互打的「名局生成器」（这个技术上现成——5 台机器人本来就能自己打）。

## P12 · Solver 数据控（GTO Wizard 重度用户）

**模拟**：350 手，VPIP 15%，bb/100 +76.2（±40，长样本里表现最好的一档）。
**UI 实证**：教练面板只给结论不给推导；会话统计只有 4 个数；无牌谱；无节点胜率；无对手倾向统计；无法 nodelocking。

**评价**：
他是全场最接近留下来的人——也是最刻薄的。「教练面板给我『按 MDF 防守』的时候，**它的依据是我看不到的**：对手范围怎么建的？建模过滤规则是什么？这些它全藏在 `gto.js` 的源码里，而界面上一个字都不展示。」对数据控来说，黑盒建议比没有建议更糟。更别提：没有 EV 显示、没有实现胜率曲线、没有对手 VPIP/PFR 逐人统计（明明机器人行为完全可统计！）、会话统计关页面即失忆。他会把这游戏当成「可以跑的扑克沙盒」留下——前提是给他数据出口。
**留存预测：若加牌谱导出与对手统计，可留存；当前版本 1 周内转为只看代码不玩游戏。**

**诉求**：本局范围/胜率可视化（引擎内部状态本来就有机）；对手逐人倾向面板；牌谱 JSON/文本导出；会话数据持久化。

## P17 · 女性竞技玩家（雀魂女帝段，反感「女生玩什么繁中服」式预设）

**模拟**：300 手，VPIP 15%，bb/100 +85.3（±40）。
**UI 实证**：6 角色全女性——对这个画像反而是「审美对了」；但角色**零玩法差异**：立绘是皮，策略是一颗脑子。教练/日志无任何性别化措辞（好）。无段位（同 P01 的全部问题）。

**评价**：
「全女性 roster 我不反感，反感的是**她们只是皮肤**。」她期待的雀魂式体验是：角色有性格、有语音、甚至有打法倾向，选角色是选「今天的作战风格」。这个游戏里选夜樱铃和选绿川小梅，坐下来之后的 500 手牌**一模一样**。对竞技女性玩家来说，这不是冒犯，是无聊——「我选了个皮，不是选了个人」。段位缺失同 P01。
**留存预测：3-5 天。审美留人，深度不留。**

**诉求**：角色打法人格化（同一均衡引擎 + 可利用的风格微差，如「小梅开得更凶、凛更紧」——注意要诚实标注这不再是严格 GTO）；角色语音/台词触发（开局、赢池、被全下）。

## P18 · 主播（B 站扑克区小主播，需要节目效果）

**模拟**：200 手，VPIP 27%，bb/100 +188.3（±55，小样本方向参考）。
**UI 实证**：无观战席、无观众互动、无覆盖层、无回放键、无 room code 多人；表情气泡是纯文本。

**评价**：
主播需要的是**可解说的戏剧结构**：宿敌、复仇局、观众下注、名场面剪辑点。这个游戏的戏剧素材其实存在（全下跑牌、边池反转、角色表情差分），但**全部缺乏放大器**：赢了一个 812 边池，屏幕上只有两行小字；机器人赢了会说一句「承让承让～」，然后呢？没有语音、没有特写、没有慢镜头。他要的「导播台」（观战 AI 互打 + 自动镜头）技术上零障碍——机器人自己就能互打——但产品里没有这个按钮。
**留存预测：会白嫖素材，但「无多人 = 观众无法参战」决定它进不了直播常驻栏。**

**诉求**：「观战模式：AI 互打 + 自动运镜 + 事件字幕」；观众弹幕决定 AI 加注的互动玩法；胜利演出（全屏立绘 + 台词）。

## 竞技群横向结论

七人共识：**引擎是合格甚至优秀的，产品围绕引擎的一切竞技基础设施为零。** 段位 0、匹配 0、牌谱 0、对手差异 0、复盘 0。最讽刺的一点：这个游戏最强的资产（可复现的 GTO 引擎 + 完全公开的内部状态）恰恰没有转化成任何数据功能。竞技群不是不肯留，是这个产品**没有给他们留下来的计数器**。
