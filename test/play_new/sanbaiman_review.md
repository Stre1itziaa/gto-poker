## A. 新大厅美术逐项审计

### A1. 舞台立绘：展示尺寸与画质 ✅ 达标
- 实测 `#stage-portrait img` 显示 **519×792**（CSS `height: min(88vh,880px)`，900 高视口下 88vh=792），加载源为 **s 级 webp 590×900**（`srcOf(id,expr,420)` → `-s` 档），下采样率 0.88——**没有放大糊**。

- 呼吸浮动（stageFloat 6s ±9px）、投影、底部对齐构图都在状态；花瓣+模糊放大剪影背景（blur 30px / brightness .38）氛围层成立，切角色时背景色随主视觉同步变（绿川→绿调，实测 `35_pack_p4`）。

## C. 改动清单（现状 → 问题 → 具体改法）

1. **经典三套服装 v2 资产缺位**
   现状：`Portraits.BASE='assets/characters_v2/'`，但 ''/club/glam 只在旧 `assets/characters/` 有图，切装即白屏 + ~97×404（`41_classic_base.png`）。
   改法（二选一，别再让 `ensureCostume` 打掩护）：a) 用 `tools/optimize.py` 把旧三套按 v2 规格补进 characters_v2（6 角色×5 表情×3 档×3 套 = 270 文件）；b) 若决定弃线，从 `Portraits.COSTUMES` 删除三套并清理 ui.js 残留引用，同时对旧档 `gto-costume` 值做一次性迁移提示。

2. **首帧 90×404 探测风暴**
   现状：存档无 `gto-costume` 时，四处 `Portraits.scan()` 调用点（main.js:360、mp.js:557/1016、ui.js:1000）可能抢在 lobby `ensureCostume` 前以 '' 服发探测。
   改法：把「默认服装键」收进 portraits.js 单点——IIFE 读档后若不在五包内直接置 `activeCostume='p1'`，删除 lobby.js 的 `ensureCostume` 兜底；或给 `scan()` 入口加 `ensurePackCostume()` 前置。

3. **p4「特色·主题」包退回重立项**
   现状：运动服/旗袍/哥特女仆大杂烩，铃发色漂成蓝主导（63_eyes3x 第 5 格），主题辨识度为零。
   改法：定一个主题（建议「夏活/泳装度假」或「学院运动会」），六张重出，交付标准加上「发色/瞳色/标志物（铃=粉发红瞳、诗织=红框眼镜）不得漂移」的验收项。

4. **p2「和趣」两张换血**
   现状：绵雪=圣诞护士、诗织=天使翼，混进职业/奇幻元素。
   改法：绵雪重出淡色浴衣（保留蓝白主色），诗织重出紫系和服+眼镜；和服本体质量已经很高，照葵夏/月见凛那两张的规格来。

5. **p3「职业」三张重出**
   现状：铃/小梅与 p2 撞和服，凛黑蕾丝偏夜店。
   改法：铃→主持人/Dealer 制服（贴部长人设）、小梅→篮球队经理人或裁判（保留元气表情）、凛→研究员白大褂（读牌魔女本命）；护士绵雪可从本包挪过去补位。

6. **表情切换零演出**
   现状：`<img>.src` 硬切，无过渡（A2）。
   改法：lobby.js `onPortraitClick` 里给 `#stage-portrait img` 加一次性 CSS class（`transform: scale(.97)→1` + 120ms opacity 淡入，`prefers-reduced-motion` 时跳过），或双 img 交叉淡入。

7. **服装页签失同步**
   现状：外部改装后大厅页签高亮停留旧包（50_final_state.png 实证）。
   改法：lobby.js `init` 里补 `root.addEventListener('gto-costume', renderCostumes)`（顺手把 `renderStage` 也挂上），与 ui.js 的监听对称。

8. **服装页签折行**
   现状：480px 侧栏放不下「标签+5 页签」，「特色·主题」孤行。
   改法：`.costume-tab` padding 6px 16px→6px 12px、字号 13.5→12.5px，或标签「服装」上移独立一行、页签整行 flex-wrap 成 3+2 对称。

9. **挂机房房主生命周期 = 房间不可加入**
   现状：开局后 phase 永不回 lobby，GBY7TC 全程拒客（B1），25 分钟保活白烧。
   改法：mp.js 加「迟到加入」——host 端收到 join 时若 `phase==='game'` 且座位有空，广播当前快照+「下一局开桌入座」队列；最小改法是给 host 加「第 N 手后自动暂停回大厅」的挂机保底。状态文案已是准确的，机制跟上即可。

10. **表情轮播无指示**
    现状：只有 11px/55% 透明度的「点击立绘换表情」提示，玩家不知有 5 差分。
    改法：舞台左下加 5 个小圆点指示器（当前表情高亮 accent 色），轮播/回退时同步，代码量 ~20 行。

11. **顶栏零盈亏显示 +0.0bb**
    现状：`bb>=0 ? '+' : '−'` 把 0 显示成正。
    改法：`bb > 0 ? '+' : bb < 0 ? '−' : ''`，零显示「0.0bb」。

12. **牌桌顶部座卡被视口裁边**
    现状：1600×900 下顶部中央座卡上缘裁掉 ~8px。
    改法：`#table-wrap` 顶部 padding +12px，或座卡顶部 max-height 让位。

13. **（测试脚本侧，非游戏）mp_guest 数字连读**
    现状：`amt = "".join(ch for ch in call_btn if ch.isdigit())` 把「全下跟注 1550（对方要 1930）」读成 15501930，误判巨注弃牌。
    改法：改用正则取第一段数字 `re.search(r'\d+', call_btn)`；本次不影响结论，已澄清不是游戏 bug。
